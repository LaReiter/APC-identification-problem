Exploring the Age-Period-Cohort identification problem in the following settings:

* Narwhal tusks:  Narwhals accumulate chemical constituents throughout their life. The physiology changes with age, which affects the rate of accumulation and the relative uptake. Simultaneously, the mineral content changes in prey and the sea water due to environmental trends (e.g. as a function of calendar year). Disentangling these effects prove hard, as we demonstrate here.
